# 디자인 참고 자료 폴더

여기에 디자인 시안이나 참고 이미지를 넣어 두세요.

- Google Stitch, Figma 시안 캡처 (PNG, JPG)
- 마음에 드는 사이트 캡처
- 원하는 색 조합 이미지

그다음 Claude Code에 이렇게 말하면 됩니다.

> /design design/references 폴더의 hero-시안.png 처럼 바꿔줘

팁: 파일 이름을 `hero-시안.png`, `전체-분위기.png` 처럼 알아보기 쉽게 지으면 Claude가 더 정확히 이해합니다.
